# TC Fast Setup 🚀

Автоматизированный скрипт для быстрой настройки сервера с Hestia CP, мониторингом и безопасностью.

## 📋 Описание проекта

Этот проект содержит набор скриптов для автоматической установки и настройки:
- **Hestia Control Panel** - панель управления сервером
- **Grafana + Prometheus + Loki** - система мониторинга
- **Fail2ban** - защита от брутфорс атак
- **nftables/iptables** - настройка файрвола
- **Node Exporter + Pushgateway** - экспортеры метрик

## 🚀 Использование

### Основная установка

```bash
# Клонирование репозитория
git clone https://github.com/Traffic-Connect/tc_fast_setup.git
cd tc_fast_setup

# Запуск установки
sudo bash script.sh
```

### Диагностика и исправление проблем

```bash
# Диагностика системы
sudo ./unified_diagnostic.sh diagnose

# Быстрое исправление
sudo ./unified_diagnostic.sh quick

# Полное исправление с подтверждением
sudo ./unified_diagnostic.sh fix

# Завершение установки (99% -> 100%)
sudo ./unified_diagnostic.sh finish

# Исправление проблем с Composer
sudo ./unified_diagnostic.sh composer
```

### Дополнительная настройка

```bash
# Настройка Promtail с GeoIP
sudo bash 2.sh

# Управление файрволом
sudo ./fw.sh status    # Статус
sudo ./fw.sh block IP  # Блокировка IP
sudo ./fw.sh unblock IP # Разблокировка IP
sudo ./fw.sh cloudflare # Обновление IP Cloudflare
```
