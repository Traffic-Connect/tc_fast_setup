## Описание

Этот проект содержит набор скриптов для автоматической установки и настройки:
- Hestia Control Panel
- Grafana + Prometheus + Loki (мониторинг)
- Fail2ban (защита от брутфорса)
- nftables/iptables (файрвол)
- Node Exporter + Pushgateway

## Файлы проекта

### Основные скрипты
- `script.sh` - Основной скрипт установки с красивым оформлением (полная версия)
- `script_fixed.sh` - Исправленная версия скрипта установки (упрощенная, с таймаутами)
- `unified_diagnostic.sh` - **НОВЫЙ**: Универсальный диагностический скрипт (объединяет все диагностические функции)

### Дополнительные утилиты
- `2.sh` - Дополнительная настройка Promtail с GeoIP
- `fw.sh` - Утилита управления файрволом

## Использование

### Установка
```bash
# Полная версия
sudo bash script.sh

# Упрощенная версия с улучшенной обработкой ошибок
sudo bash script_fixed.sh
```

### Диагностика и исправление проблем
```bash
# Диагностика системы
sudo ./unified_diagnostic.sh diagnose

# Быстрое исправление
sudo ./unified_diagnostic.sh quick

# Полное исправление с подтверждением
sudo ./unified_diagnostic.sh fix

# Завершение установки (99% -> 100%)
sudo ./unified_diagnostic.sh finish
```

### Дополнительная настройка логов
```bash
sudo bash 2.sh
```

### Управление файрволом
```bash
sudo ./fw.sh status    # Статус
sudo ./fw.sh block IP  # Блокировка IP
sudo ./fw.sh unblock IP # Разблокировка IP
sudo ./fw.sh cloudflare # Обновление IP Cloudflare
```
