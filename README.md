## 🔧 Быстрая установка

### ⚡ Однострочная установка
```bash
curl -sSL https://raw.githubusercontent.com/Traffic-Connect/tc_fast_setup/main/install.sh | sudo bash
```

### 📦 Скачивание и установка
```bash
# Скачивание
wget https://github.com/Traffic-Connect/tc_fast_setup/archive/main.zip
unzip main.zip
cd tc_fast_setup-main

# Быстрая установка
sudo ./install.sh --full

# Интерактивная установка
sudo ./install.sh
```

### 🎛️ Режимы установки

| Режим | Команда | Описание |
|-------|---------|----------|
| **Полная установка** | `./install.sh --full` | Все компоненты автоматически |
| **Интерактивная** | `./install.sh` | Выбор компонентов |
| **Только HestiaCP** | `./install.sh --hestia` | Панель управления |
| **Только мониторинг** | `./install.sh --monitoring` | Grafana + Prometheus + Loki |
| **Дополнительные** | `./install.sh --additional` | Шаблоны + скрипты |

## ⚙️ Детальная настройка

## 🔒 Безопасность

### 🔐 Улучшенная генерация паролей

| Уровень сложности | Символы | Пример | Безопасность |
|-------------------|---------|--------|--------------|
| **Низкая** | A-Z, a-z, 0-9 | `Kj8mN2pQ9rS` | ⭐⭐ |
| **Средняя** | + базовые символы | `Kj8m+N2pQ9rS` | ⭐⭐⭐ |
| **Высокая** | Все символы | `Kj8m#N2pQ9rS@` | ⭐⭐⭐⭐⭐ |

### 🛡️ Проверка целостности
- **SHA256 проверка** всех загруженных файлов
- **GPG проверка** подписей пакетов
- **SSL проверка** всех соединений
- **Валидация URL** перед загрузкой

### 🔄 Автоматический rollback
```bash
# При ошибке установки автоматически:
1. Останавливаются установленные сервисы
2. Удаляются конфигурационные файлы
3. Создается резервная копия логов
4. Восстанавливается предыдущее состояние
```

## 🛠️ Устранение неполадок

### ❌ Частые проблемы

#### 1. Недостаточно места на диске
```bash
# Проверка места
df -h

# Очистка кэша
sudo rm -rf /var/cache/install/*

# Очистка временных файлов
sudo rm -rf /tmp/grafana.deb /tmp/prometheus.tar.gz
```

#### 2. Порт уже занят
```bash
# Поиск процесса
sudo netstat -tlnp | grep :3000

# Изменение порта
echo 'GRAFANA_PORT="3001"' >> config.local.sh
```

#### 3. Ошибки загрузки
```bash
# Проверка интернета
ping 8.8.8.8

# Проверка DNS
nslookup github.com

# Очистка кэша
sudo rm -rf /var/cache/install/*
```

#### 4. Ошибки установки компонентов
```bash
# Детальные логи
sudo journalctl -u grafana-server -n 50

# Перезапуск сервиса
sudo systemctl restart grafana-server

# Проверка конфигурации
sudo grafana-server --config /etc/grafana/grafana.ini
```

### 🔧 Полезные команды
```bash
# Проверка версий
```

## 🔄 Обновление

### 📥 Обновление установщика
```bash
# Скачивание новой версии
wget https://github.com/Traffic-Connect/tc_fast_setup/archive/main.zip
unzip main.zip
cd tc_fast_setup-main

# Запуск обновления
sudo ./install.sh --update
```

### 🔄 Обновление компонентов
```bash
# Обновление Grafana
sudo apt update && sudo apt upgrade grafana

# Обновление Prometheus
sudo systemctl stop prometheus
# Скачать новую версию и заменить
sudo systemctl start prometheus
```
