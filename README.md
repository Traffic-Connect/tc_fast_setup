# Traffic Connect Server Installation

Автоматический установщик для сервера с HestiaCP, системой мониторинга и дополнительными компонентами.

## Быстрая установка

```bash
# Скачивание
git clone <repository-url>
cd Install

# Быстрая установка
sudo ./install.sh --full

# Интерактивная установка
sudo ./install.sh
```

## Компоненты

- **HestiaCP** - Панель управления сервером (порт 8083)
- **Grafana** - Визуализация метрик (порт 3000)
- **Prometheus** - Сбор метрик (порт 9090)
- **Loki** - Агрегация логов (порт 3100)
- **Node Exporter** - Системные метрики (порт 9100)
- **Pushgateway** - Прием push-метрик (порт 9091)
- **Fail2Ban** - Защита от атак
- **Шаблоны Nginx** - Оптимизированные конфигурации
- **Schemes Scripts** - Автоматизация задач
- **Link Manager** - Управление ссылками
- **BadBot Protection** - Защита от ботов

## Команды

```bash
# Тестирование
sudo ./install.sh --test

# Проверка системы
sudo ./install.sh --validate

# Справка
sudo ./install.sh --help
```

## Системные требования

- Ubuntu 20.04+ или Debian 11+
- x86_64 архитектура
- 1GB RAM минимум
- 2GB свободного места
- Интернет соединение

## Структура проекта

```
Install/
├── install.sh                    # Главный установщик
├── install_complete.sh           # Полная установка
├── install_tools.sh              # Дополнительные компоненты
├── config.sh                     # Конфигурация
├── lib/                          # Библиотеки функций
├── tools/                        # Дополнительные компоненты
├── Components/                   # Шаблоны Nginx
└── tests/                        # Тесты
```

## Пароли и логи

- **Пароли сохраняются в:** `/root/credentials.txt`
- **Логи установки:** `/var/log/install/`

## Безопасность

- Автоматическая генерация сложных паролей
- Проверка целостности файлов
- Автоматический rollback при ошибках
- Настройка firewall и fail2ban
