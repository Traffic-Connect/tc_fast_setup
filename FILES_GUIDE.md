# 📁 Руководство по файлам Traffic Connect Server

## 🚀 ОСНОВНЫЕ СКРИПТЫ УСТАНОВКИ

### 1. `traffic_connect.sh` - **ГЛАВНЫЙ УПРАВЛЯЮЩИЙ СКРИПТ**
**Назначение:** Единый скрипт для всех операций с проектом
**Размер:** 63KB, 1566 строк
**Запуск:**
```bash
# Интерактивное меню
./traffic_connect.sh

# Командная строка
./traffic_connect.sh --install              # Основная установка
./traffic_connect.sh --install-improved     # Улучшенная установка
./traffic_connect.sh --install-monitoring   # Только мониторинг
./traffic_connect.sh --install-hestia       # Только HestiaCP
./traffic_connect.sh --fix-dpkg             # Исправить блокировки dpkg
./traffic_connect.sh --fix-ssl              # Исправить SSL таймауты
./traffic_connect.sh --fix-composer         # Исправить проблемы Composer
./traffic_connect.sh --check-security       # Проверить безопасность
./traffic_connect.sh --show-credentials     # Показать пароли
./traffic_connect.sh --check-version        # Проверить версии
./traffic_connect.sh --force-update         # Принудительное обновление
```

**Функции:**
- ✅ Установка всех компонентов
- ✅ Исправление проблем
- ✅ Проверка безопасности
- ✅ Управление паролями
- ✅ Обновление системы

## 🎯 РЕКОМЕНДАЦИИ ПО ИСПОЛЬЗОВАНИЮ

### **Для первой установки на сервере:**
```bash
# 1. Клонирование проекта
git clone https://github.com/Traffic-Connect/tc_fast_setup.git
cd tc_fast_setup

# 2. Настройка прав
chmod +x *.sh

# 3. Запуск улучшенной установки
./install_improved.sh
```

### **Для быстрой установки:**
```bash
# Использование единого скрипта
./traffic_connect.sh --install-improved
```

### **Для установки только мониторинга:**
```bash
./traffic_connect.sh --install-monitoring
```

### **Для исправления проблем:**
```bash
# Блокировки dpkg
./traffic_connect.sh --fix-dpkg

# SSL таймауты
./traffic_connect.sh --fix-ssl

# Проблемы Composer
./traffic_connect.sh --fix-composer
```

### **Для проверки системы:**
```bash
# Проверка безопасности
./traffic_connect.sh --check-security

# Показать пароли
./traffic_connect.sh --show-credentials

./traffic_connect.sh --check-version
```

## 🎯 ИТОГОВЫЕ РЕКОМЕНДАЦИИ

### **Основной файл для использования:**
**`traffic_connect.sh`** - единый скрипт для всех операций

### **Для установки:**
1. **`install_improved.sh`** - для стабильной установки с перезагрузкой
2. **`install.sh`** - для быстрой установки на чистом сервере

### **Порядок использования:**
1. Клонировать проект
2. Настроить права доступа
3. Запустить `traffic_connect.sh` или `install_improved.sh`
4. Следовать инструкциям на экране

### **Для поддержки:**
- Использовать `traffic_connect.sh` для исправления проблем
- Проверять безопасность через `--check-security`
- Просматривать пароли через `--show-credentials`
