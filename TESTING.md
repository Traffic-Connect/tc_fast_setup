# 🧪 Тестирование Traffic Connect Server

## 📋 Подготовка к тестированию

### Требования к серверу
- **ОС:** Ubuntu 20.04/22.04 или Debian 11/12
- **RAM:** минимум 2GB
- **Диск:** минимум 10GB свободного места
- **Интернет:** стабильное подключение
- **Права:** root доступ

### Создание тестового сервера

1. **Создайте новый VPS** в любом провайдере (DigitalOcean, Vultr, Hetzner, etc.)
2. **Выберите Ubuntu 20.04/22.04** или Debian 11/12
3. **Минимальная конфигурация:** 2GB RAM, 1 CPU, 20GB SSD
4. **Подключитесь по SSH** с правами root

## 🚀 Быстрое тестирование

### Способ 1: Прямая установка (рекомендуется)

```bash
# Загрузка и установка в одну команду
curl -sSL https://raw.githubusercontent.com/Traffic-Connect/tc_fast_setup/main/quick_install.sh | sudo bash
```

### Способ 2: Скачивание и запуск

```bash
# Скачивание скрипта
wget https://raw.githubusercontent.com/Traffic-Connect/tc_fast_setup/main/quick_install.sh

# Сделать исполняемым
chmod +x quick_install.sh

# Запуск установки
sudo ./quick_install.sh
```

### Способ 3: Клонирование репозитория

```bash
# Клонирование
git clone https://github.com/Traffic-Connect/tc_fast_setup.git
cd tc_fast_setup

# Запуск установки
sudo bash install.sh --install
```

## 📊 Процесс установки

### Этапы установки (15-30 минут)

1. **✅ Проверка системы** - совместимость и требования
2. **✅ Инициализация** - создание директорий и логирование
3. **✅ Установка HestiaCP** - основная панель управления
4. **✅ Настройка безопасности** - fail2ban, iptables, SSH
5. **✅ Установка мониторинга** - Grafana, Prometheus, Loki
6. **✅ Установка шаблонов** - веб-конфигурации
7. **✅ Финальная настройка** - валидация и сохранение данных

### Что происходит во время установки

- **Автоматическая генерация паролей** для всех сервисов
- **Подробное логирование** каждого этапа
- **Проверка совместимости** системы
- **Установка зависимостей** и компонентов
- **Настройка безопасности** и файрвола
- **Валидация установки** и проверка служб

## 🔍 Проверка установки

### Проверка служб

```bash
# Статус основных служб
systemctl status admin nginx mysql grafana-server prometheus

# Проверка всех служб мониторинга
systemctl status node_exporter loki pushgateway fail2ban_exporter
```

### Проверка веб-интерфейсов

```bash
# Получение IP сервера
SERVER_IP=$(hostname -I | awk '{print $1}')

# Проверка доступности
curl -I http://$SERVER_IP:8083  # HestiaCP
curl -I http://$SERVER_IP:3000  # Grafana
curl -I http://$SERVER_IP:9090  # Prometheus
curl -I http://$SERVER_IP:3100  # Loki
curl -I http://$SERVER_IP:9100  # Node Exporter
```

### Просмотр результатов

```bash
# Учетные данные
cat /root/traffic_connect_credentials.txt

# Логи установки
tail -f /var/log/traffic_connect/install.log

# Статус установки
cat /var/log/traffic_connect/install.json
```

## 🌐 Доступ к сервисам

После установки вы получите доступ к:

### HestiaCP (Панель управления)
- **URL:** `https://YOUR_SERVER_IP:8083`
- **Пользователь:** `TrafficAdmin`
- **Пароль:** сгенерированный автоматически

### Grafana (Мониторинг)
- **URL:** `http://YOUR_SERVER_IP:3000`
- **Пользователь:** `admin`
- **Пароль:** сгенерированный автоматически

### Prometheus (Метрики)
- **URL:** `http://YOUR_SERVER_IP:9090`
- **Пользователь:** `prometheus`
- **Пароль:** сгенерированный автоматически

### Другие сервисы
- **Loki:** `http://YOUR_SERVER_IP:3100`
- **Node Exporter:** `http://YOUR_SERVER_IP:9100`
- **Pushgateway:** `http://YOUR_SERVER_IP:9091`

## ⚠️ Возможные проблемы

### Ошибка Composer
```
❌ Ошибка Composer при установке HestiaCP
```
**Решение:** Скрипт автоматически исправляет эту проблему

### Требуется перезагрузка
```
🔄 ТРЕБУЕТСЯ ПЕРЕЗАГРУЗКА СИСТЕМЫ
```
**Решение:** Подтвердите перезагрузку, установка продолжится автоматически

### Проблемы с сетью
```
❌ Не удалось загрузить установщик HestiaCP
```
**Решение:** Проверьте подключение к интернету и доступность GitHub

### Недостаточно места
```
❌ Недостаточно свободного места на диске
```
**Решение:** Убедитесь, что на диске минимум 10GB свободного места
